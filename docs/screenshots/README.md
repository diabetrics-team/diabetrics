# Экраны бота

Собраны из **реальных ответов бота** во время автоматической репетиции демо
(`python scripts/demo_rehearsal.py --runs 1 --port 1337 --transcript …`): все тексты, кнопки и график —
ровно то, что отправил бот. Оформление чата условное (не скриншот приложения Telegram).
После репетиции с телефонами их можно заменить настоящими снимками экрана.

| Файл | Что на экране |

| `01_start.png` | `/start`: приветствие, дисклеймер, вопрос об адресе Nightscout |

| `03_trusted_invite.png` | `/trusted`: ссылка-приглашение и подтверждение «Боря теперь ваше доверенное лицо» |
