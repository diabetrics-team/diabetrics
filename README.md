# DiaBetrics

Telegram-бот, который следит за данными непрерывного мониторинга глюкозы (CGM) через Nightscout и присылает уведомления по уровням важности.

> **Учебный проект.** DiaBetrics не является медицинским изделием и не заменяет консультацию врача. Не принимайте решения о дозе инсулина только по его уведомлениям.

**Статус:** в разработке, сдача 14.11.2026. Раздел «Запуск» описывает целевой вид; актуальное состояние — в ветке `dev`.

## Что умеет

- **Три уровня уведомлений**
  - 🔴 критические: сахар ниже 3.0, прогноз падения ниже 3.0, выше 13.9 дольше часа, пропал сигнал при низком сахаре
  - 🟠 важные: ниже 3.9, выше 10.0 дольше часа, быстрое падение или рост, нет данных 20 минут
  - 🔵 стандартные: возврат в диапазон, дневная сводка
- **Режимы:** Обычный · Не беспокоить · Ночной · Учёба/работа · После еды · После коррекции гипо. Ни один режим не отключает критические уведомления.
- **Доверенное лицо:** если на критическое уведомление нет ответа N минут, сообщение уходит близкому человеку.
- **Прогноз на 20–30 минут** — линейная модель по последним показаниям.
- **NutriLens:** фото еды → оценка КБЖУ → режим «После еды» одной кнопкой.
- **Защита от ложных тревог:** одиночные выбросы датчика и колебания у порога не вызывают лавину сообщений.

## Как это работает

```
CGM-датчик → Nightscout → клиент → очистка → прогноз → движок уведомлений → эскалация → Telegram
                                                              ▲
                                             режим пользователя, история, время
```

Бот раз в минуту забирает новые показания из Nightscout, считает прогноз и решает, нужно ли уведомление. Движок уведомлений — чистая функция, поэтому всё поведение проверяется тестами на готовых сценариях.

| Каталог | Что внутри |
|---|---|
| `app/models.py`, `clock.py`, `db.py`, `pipeline.py` | общие типы, единые часы, база, основной цикл |
| `app/ns/` | клиент Nightscout и очистка данных |
| `app/forecast.py`, `metrics.py`, `plot.py`, `nutrilens.py` | прогноз, статистика, график, анализ фото |
| `app/alerts/` | правила, режимы, антиспам, эскалация |
| `app/bot/` | команды, клавиатуры, тексты сообщений |
| `fake_cgm/` | генератор тестовых данных и мини-Nightscout |
| `tests/` | тесты |

**Стек:** Python 3.11 · aiogram 3 · APScheduler · SQLite + SQLAlchemy · httpx · numpy · matplotlib · Docker Compose.

## Запуск

```bash
git clone <адрес репозитория> && cd <папка>
cp .env.example .env        # заполнить значения
docker compose up -d
```

| Переменная `.env` | Значение |
|---|---|
| `BOT_TOKEN` | токен бота от @BotFather |
| `VISION_API_KEY` | ключ сервиса распознавания фото (NutriLens) |
| `CLOCK` | `system` — обычная работа, `nightscout` — время берётся с сервера (для демо) |
| `DATABASE_URL` | по умолчанию `sqlite:///data/diabetrics.db` |

Адрес и токен Nightscout каждый пользователь вводит в боте сам. Файл `.env` в репозиторий не попадает.

### Без датчика: фейковый Nightscout

```bash
python fake_cgm/fake_cgm.py --list                                        # 14 сценариев
python fake_cgm/fake_cgm.py --serve --scenario night_hypo --speed 60      # http://localhost:1337
```

В боте укажите адрес `http://localhost:1337`, в `.env` — `CLOCK=nightscout`. Ночная гипогликемия проиграется за несколько минут. Подробнее — `fake_cgm/README.md`.

### Тесты

```bash
pytest
```

Ожидаемое поведение для каждого сценария лежит в `fake_cgm/data/scenarios.json`.

## Команды бота

| Команда | Действие |
|---|---|
| `/start` | подключение Nightscout |
| `/now` | текущий сахар, тренд, прогноз, режим |
| `/mode` | сменить режим |
| `/graph` | график за последние часы |
| `/stats` | время в диапазоне, средний сахар, число гипо |
| `/trusted` | привязать или отвязать доверенное лицо |
| `/settings` | время до эскалации, часы ночного режима |
| фото еды | оценка КБЖУ |

## Разработка

- `main` — стабильные версии, `dev` — рабочая ветка, задачи — в `feature/<название>` или `fix/<название>` от `dev`.
- Одна задача = одна ветка = один pull request в `dev`, нужно одно одобрение. Прямые пуши в `main` и `dev` закрыты.
- Коммиты: `feat:`, `fix:`, `test:`, `docs:`.
- Секреты (токены, ключи) — только в `.env`.

## Команда

| Роль | Зона |
|---|---|
| Платформа и данные (тимлид) | каркас, Nightscout, база, основной цикл, деплой |
| Движок уведомлений | правила, режимы, эскалация |
| Telegram-бот | интерфейс, доверенное лицо, настройки |
| Прогноз и NutriLens | прогноз, анализ фото, графики, метрики |
