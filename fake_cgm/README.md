## Формат — как у настоящего Nightscout

```json
{"_id":"…","type":"sgv","sgv":120,"date":1794169500000,
 "dateString":"2026-11-08T20:25:00.000Z","direction":"FortyFiveDown","trend":5,"device":"fake-cgm"}
```
- `sgv` в mg/dL → ммоль/л = sgv / 18. Поля `mmol` больше нет (в v1 было, в настоящем NS его нет).
- В `dirty_data` встречаются: дубликаты от второго загрузчика (+8 с), запись `type: "mbg"`, запись без `direction`, `sgv: 5` (код ошибки датчика). Клиент обязан это пережить.

## Мини-Nightscout

- `GET /api/v1/entries.json?count=N`, `?find[date][$gt]=<ms>`; `/api/v1/entries/sgv.json`; `/api/v1/status.json`
- `--token X` — без `?token=X` или заголовка `api-secret: sha1(X)` отвечает 401
- `--speed 60` — минута сценария за секунду; `--skip 150` — начать со 150-й минуты (сразу к интересному)
- «Сейчас» при ускорении — только из `serverTimeEpoch` (через общий `Clock`), иначе таймеры режимов и эскалации разойдутся с данными
